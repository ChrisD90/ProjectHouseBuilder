Projekt vollständig zurücksetzen

Löscht unwiderruflich alle Projektdaten: Aufgaben, Angebote, Kosten, Rechnungen, Finanzierungen, Firmen, eigene Kategorien und hochgeladene Dokumente.

Die App legt vorher verpflichtend ein geprüftes Komplettbackup im ausgewählten Ordner an. Ist das nicht möglich, findet kein Reset statt. Systemkategorien und das Datenbankschema bleiben erhalten; die Projektliste ist anschließend leer.

Nur bei lokalem SQLite-Betrieb verfügbar. NAS/PostgreSQL und gespeicherte Backups werden nicht gelöscht.

Wiederherstellen

Wähle ein geprüftes Backup aus dem eingerichteten Speicher oder lade ein Backup-ZIP hoch. Die App prüft zunächst dessen Integrität, bevor du die Wiederherstellung ausdrücklich bestätigst.

Das bisherige Terminalverfahren bleibt erhalten: auf dem Mac python3 backup_manager.py restore "DATEI.zip" --yes; auf der Synology weiterhin pg_restore und die Dokumentwiederherstellung wie in synology/README.md. Bei produktiven Daten vorab eine externe Kopie prüfen.

Lokale OCR-Diagnose

Prüft, ob auf dem Anwendungsserver Tesseract, Poppler und das deutsche Sprachpaket verfügbar sind. Angebote und Belege werden jetzt seitenweise gelesen; Bilder und gescannte PDF-Seiten nutzen OCR.

OCR reparieren – Schritte für die laufende Installation

Die Pakete stehen bereits im aktuellen Dockerfile. Fehlende Programme bedeuten meist, dass die laufende App noch ein älteres Image verwendet. Ein einfacher Neustart lädt keine neuen Pakete.

Synology: Container Manager → Projekt → sicherstellen, dass als App-Build der aktuelle Projektordner mit Dockerfile und compose.synology.yaml verwendet wird. App-Image neu bauen und App-Container aus dem neuen Image erstellen, ohne Daten-Volumes zu entfernen.

Alternativ im Projektordner per SSH:

docker compose -f compose.synology.yaml build --no-cache app
docker compose -f compose.synology.yaml up -d --no-deps app
docker compose -f compose.synology.yaml exec app sh -c 'command -v tesseract; command -v pdftoppm; tesseract --list-langs'

Danach die OCR-Diagnose erneut starten. PostgreSQL- und private Daten-Volumes ausdrücklich beibehalten.

Beim direkt auf dem Mac gestarteten Programm können die benötigten Werkzeuge über Homebrew installiert werden:

brew install tesseract tesseract-lang poppler

Danach den Python-App-Prozess neu starten und die OCR-Diagnose wiederholen.

Backup-Zielordner festlegen

Wähle einen für die Anwendung erreichbaren Ordner. Auf der Synology werden nur Verzeichnisse innerhalb des eingebundenen Backup-Speichers angeboten.

Existierende Backups werden beim Wechsel nicht verschoben. Neue Sicherungen landen ausschließlich im neuen Zielordner.
