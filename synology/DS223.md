# Synology DS223 (ARM64, 2 GB RAM)

DS223: Realtek RTD1619B, ARMv8/ARM64, 2 GB RAM. Die App ist auf einen Gunicorn-Worker und zwei Threads voreingestellt. Die Python-, PostgreSQL- und Caddy-Images müssen als ARM64-Varianten geladen werden.

## Vor der Installation

1. Unter DSM > Paket-Zentrum prüfen, ob Container Manager für die installierte DSM-Version angeboten wird. Neuere Synology-Kompatibilitätslisten enthalten die DS223; ältere Installationen können abweichen.
2. Container Manager nur über offiziell unterstützte DSM-Pakete installieren. Wenn das Paket fehlt, DSM-Version prüfen statt inoffizielle Docker-Hacks einzusetzen.
3. Keine weiteren RAM-intensiven Container parallel starten. Bei 2 GB RAM ist die Auslastung beim Image-Build und ersten Start zu beobachten.
4. NAS-IP per DHCP-Reservierung festlegen; HTTPS-Port 8443 nur im Heimnetz nutzen, keine Router-Portweiterleitung einrichten.
5. Installation gemäß synology/README.md über Container Manager > Projekt mit compose.synology.yaml und sicherer .env.

Für die Anmeldung und die installierbare PWA ist die Einrichtung des lokalen Caddy-Zertifikats auf jedem Gerät erforderlich. Die Originalangebote sowie Datenbank und Dokumente liegen ausschließlich lokal in persistenten Volumes, nicht in diesem öffentlichen Repository.

Eine praktische Installation auf einer echten DS223 wurde noch nicht getestet.
